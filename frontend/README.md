# To-Do List App

A full-stack to-do list application built with React (Vite) on the frontend
and Node.js/Express on the backend, using MongoDB as database.

Users register and login to manage their own private task list. All task
endpoints are secured behind JWT authentication and three middleware layers.

## Features

- User registration and login with JWT sessions
- Create, edit, complete, and delete tasks
- Dashboard with All / Active / Completed filter tabs
- Live 140-character counter on task forms
- Responsive design using Bootstrap

## Installation

1. Navigate into the project folder

2. Install the dependencies with:

   ```bash
   npm i
   ```

3. Run the App

   ```bash
   npm run dev
   ```

4. Open the webpage on your browser
   ```bash
   http://localhost:5173/
   ```
